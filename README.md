# Oldtime app source

Public source snapshot for oldtimemessenger/alpha.

This repository contains the active Oldtime web app, Cloudflare API, mobile wrapper, and required shared source packages. It excludes prior-address and mockup artifacts, archives, uploaded reference assets, generated builds, production user records, secrets, and workspace Git history.

Use the existing package and Wrangler configuration. Supply secrets through the provider's secret settings; never add them to source control. This snapshot does not publish or deploy the app automatically.
